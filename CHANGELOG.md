# Changelog

## Unreleased

- Flow control: If / Else / End if, Loop, Loop while, Exit loop, Label, Go to label, Stop workflow, with conditions on text, numbers, regex, visible images, windows and files.
- Mouse: middle click and drag and drop.
- Windows and apps: launch application, open file or URL, focus / wait for / close window by title, run Command Prompt or PowerShell commands, take screenshots.
- Dialogs: show message and ask for input during a run.
- Data: set clipboard, increase variable, transform text, date and time, random number, read and write text files.
- Editor: action search, indented blocks, automatic End if / End loop, new actions insert below the selected step.

## 0.1 — 2026-11-24

Initial release of ScreenFlow, a native Windows application for creating and running visual desktop automation workflows.

- Mouse and keyboard automation.
- Computer-vision targeting of screen elements.
- Reusable workflows with variables and repetition.
- Windows Fluent interface with light and dark themes.
