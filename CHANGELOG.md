# Changelog

## 0.1 — 2026-11-24

- Native Windows workflow editor using Fluent controls, Segoe UI Variable fonts, and the mouse-circle application icon.
- System, Light, and Dark appearance modes with a saved per-user preference.
- Mouse clicks, movement, scrolling, Unicode typing, keyboard shortcuts, delays, and repeated workflows.
- OpenCV visual target capture, image matching, click-on-match, and wait-for-image actions.
- Browser focus and Ctrl+T actions, including support for open Octo/Octium profile windows.
- URL copying, clipboard reads, variables, and portable JSON workflows with embedded image targets.
- F8 emergency stop and step-by-step activity logging.
- Visible minimize, maximize/restore, and close controls, with duplicate caption branding removed.
- Contextual workflow action buttons that disable when no action is selected or movement is unavailable.
- Nineteen isolated self-tests and an interactive practice-window diagnostic.

Live Octo and real-website compatibility have not been verified by the assistant. Development diagnostics target synthetic browser records and ScreenFlow's own practice window.
